# Yellow GlitchLab R01 — эксперимент для Flipper Zero

## Что сделано
В отдельном приложении Yellow GlitchLab (не вместо основного Yellow Native) создан GlitchDex из 105 внутренних индексов Pokémon Yellow: 0x00, 39 вариантов MissingNo. и все 65 индексов 0xBF–0xFF. У каждого пункта есть превью и визуальный призыв рядом с персонажем. Призыв не меняет команду, игровое состояние, боевые механики или ROM; это безопасная демонстрация.

Удержание OK в мире игры/меню — открыть/закрыть GlitchDex. Вверх/Вниз — выбрать; Влево/Вправо — переход на 8 позиций; короткое OK — открыть экземпляр, следующее OK — призвать; Back — вернуться.

## Настоящие спрайты и ограничения
Для MissingNo. 0xB6, 0xB7, 0xB8 используется адаптированная оригинальная графика fossil Kabutops, fossil Aerodactyl и Ghost из закреплённого pret/pokeyellow. Для остальных некорректных индексов визуализация детерминированная и синтетическая (помечена SAFE PREVIEW): ROM-данных в локальном проекте нет. Это НЕ точная эмуляция битой графики, глюков памяти, действий или боёв Pokémon Yellow. Многие из этих персонажей зависают на оригинальном Game Boy из-за ошибочных указателей спрайтов, а не нехватки оперативной памяти. Повреждение памяти намеренно не воспроизводится.

## Отдельные сборки
yellow_glitchlab.fap устанавливается в /ext/apps/Games/ и не меняет прошивку или штатное приложение. Оно использует изолированное сохранение /ext/apps_data/yellow_glitchlab/save_v13.dat и не импортирует основной прогресс. Основа игрового порта — локальная R12C2, частичная адаптация Pokémon Yellow.

Вторая ветка experiment/glitchdex-desktop дополняет модифицированный главный экран PikaCore на базе Momentum: удержание OK на домашнем экране открывает каталог; выбор/призыв отображает глитч-покемона вместо Пикачу; короткий Back возвращает Пикачу. Этот функционал требует сборки и отдельной установки экспериментальной прошивки, одной установки FAP недостаточно. Существующая прошивка не перепрошивалась.

## Установка
Для тестирования только приложения: скопировать yellow_glitchlab.fap на microSD в /ext/apps/Games/ через qFlipper/обычную файловую передачу и открыть в Games. Оригинальный Yellow Native остается отдельно.

Прошивку для главного экрана использовать только на совместимом Flipper с заранее сделанным бэкапом; автоматического прошивания и изменения пользовательских данных здесь нет.
