## Неподвижные правила
1. Никаких ложных заявлений о полном порте, точности Gen1 или проверке на реальном устройстве.
2. Не перезаписывать старые сохранения: каждый релиз получает отдельную версию `save_vNN.dat`.
3. Не изменять прошивку / Noosphere Pika без отдельного отката и доказательной проверки.
4. Уровни, атаки, ресурсы и API сверять с pinned upstream; неисправные тесты чинить только с обоснованием, не скрывать.
5. Предпочитать ограниченную, но прошедшую проверки функциональность необозримой недостоверной реализации.

## Отчёт о попытке аппаратной диагностики
- 2026-10-23: ноутбук DESKTOP-PUHG2PP доступен по SSH (hostname/whoami подтверждены). USB/COM Flipper через доступные действия удалённой диагностики **не подтверждён**; командный доступ к Windows PnP недоступен. Не устанавливать FAP на устройство и не выдавать это за проверенный запуск до появления доказательной проверки.
