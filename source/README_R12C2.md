# Pokémon Yellow Native — R0.12-C2 / Save schema v13

Частичный нативный порт для Flipper Zero, ARM Cortex-M4, Momentum mntm-012 SDK API 87.1. **Не завершённая оригинальная игра, не эмулятор Game Boy.**

## Изменения

- Добавлен **сон** со счётчиком 1–7 ходов. Счётчик уменьшается при попытке выполнить ход; при достижении нуля покемон просыпается, но этот ход всё равно пропускает — согласно `CheckPlayerStatusConditions` / `CheckEnemyStatusConditions` из `pret/pokeyellow`.
- Добавлена **заморозка**: блокирует атакующие действия до внешнего лечения; самопроизвольного оттаивания в базовом Gen1 нет. Оттаивание от некоторых Fire-атак и специальные случаи ещё не реализованы.
- Добавлен **Toxic**, счётчик растущего периодического урона после действия. Множитель 1, 2, 3 … и ограничение до 15 — **техническое приближение**, а не полное воспроизведение всех граничных особенностей Gen1.
- Ради минимального объёма памяти счётчики Sleep/Toxic кодируются в **одном байте статуса** покемона. Перечисление: None, PAR, BRN, PSN, FRZ, Sleep1..7, Toxic1..15.
- После завершения боя или смены активного покемона Toxic нормализуется до обычного PSN; пойманный под Toxic покемон также получает PSN. Pokémon Center лечит все эти состояния.
- Захват Basic Poké Ball использует бонус к первой случайной проверке: +12 для BRN/PSN/PAR/Toxic, +25 для FRZ/Sleep.
- В интерфейсе статусы показываются как `SLP`, `FRZ`, `PSN`, `BRN`, `PAR`.
- Новый **логический формат сохранений 13**, файл `/ext/apps_data/yellow_native/save_v13.dat`. Побайтовая структура `YellowSave` неизменна по сравнению с v12, но допустимые значения статуса расширены. Перед миграцией v12 проверяются контрольная сумма и допустимость старых состояний. Файлы v12c/v12b/v12/v11/v10 не перезаписываются.

## Проверки

- 16 C-наборов: от `test_core.c` до `test_status12c2.c`, в том числе тесты Sleep/Freeze gate+PP, Toxic, capture, сохранений и отвергания повреждённого ввода, — PASS.
- 2 Python-проверки pinned upstream, включая оригинальную логику сна/заморозки, Toxic/HP и бонусы поимки, — PASS.
- 16 000 детерминированных игровых переходов в стресс-тесте — PASS.
- Компиляция ARM/APPCHK SDK API 87.1 — PASS.

## Чего пока нет

- Реальных пользовательских/вражеских приёмов для наложения сна, заморозки и Toxic в текущей ограниченной таблице доступных видов — тестирование этих статусов проведено прямой установкой состояния в C-сценариях.
- Оттаивание Fire-атаками, полноценная Gen1 битовая схема статусов, все исключения и тонкости Toxic, статусные лекарства, перенос прогресса из настоящего ROM-сохранения.
- Никаких измерений FPS или проверки непосредственно на Flipper — устройство в этой сессии не подтверждено по USB.

Прошивка и отдельный PikaCore/Noosphere Pika (неизменяемая индивидуальная идентичность HTask1k0) не изменяются. Права на Pokémon и графику сохраняются за их владельцами; приватное тестирование.

Upstream: https://github.com/pret/pokeyellow, pinned revision в `source_manifest.json`.
