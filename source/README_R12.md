# Pokémon Yellow Native R0.12 — Type-Matchup Foundation

**Частичный нативный порт Pokémon Yellow для Flipper Zero** (C / ARM Cortex-M4 / Momentum mntm-012 API 87.1), а не Game Boy эмулятор и не полная игра.

## Сделано в R0.12-A

- Встроены **все 82 записи** оригинальной таблицы взаимодействия типов первого поколения из `pret/pokeyellow/data/types/type_matchups.asm`.
- Поддержаны один и два защитных типа, множители 0%, 25%, 50%, 100%, 200%, 400%. Иммунитет обнуляет урон; применяется в общем расчёте урона (с сохранением предыдущих учётов STAB, критов и характеристик).
- Специфичные для Gen1 факты проверены: Normal→Ghost = 0; Ghost→Psychic = 0; Bug→Poison = 200%; Poison→Bug = 200%; Ground→Flying = 0; Electric→Water/Flying = 400%.
- Значения типов соответствуют 8-битным идентификаторам оригинального Game Boy, а не произвольной современной нумерации.
- Генератор `tools/generate_type_matchups.py` строит `yellow_type_matchups.generated.h` из закреплённого исходника; `tests/test_type_source12.py` сравнивает итоговую таблицу с upstream **запись за записью**.
- Новые независимые сохранения `save_v12.dat`, с проверяемой миграцией из `save_v11.dat` или `save_v10.dat`. Оба старых файла сохраняются.

## Проверено

- **13 C-наборов**: от R0.3 до нового test_type12 и test_migration12.
- Две проверки Python: pinned исходные данные и полное совпадение таблицы из 82 записей.
- Стресс-тест 16 000 переходов, сохранение/восстановление, выбор приёма и случай победы — PASS.
- ARM SDK сборка и APPCHK: PASS. Файлы релиза хранятся с SHA-256 и тестовыми доказательствами.

## Следующие задачи

R0.12-B: канонический конвейер эффектов атак и проверка порядка округлений. R0.12-C: более полный набор статусов и продолжение боевой симуляции. Дальше — Route 2, Viridian Forest, NPC-скрипты, предметы, Pokédex и PC.

**Честные ограничения:** 82 записи таблицы перенесены, но общая боевая формула пока не полностью побайтово идентична Gen1 (например, промежуточные округления). Нет полной команды 151 видов, регионов, сюжета или звука. На реальном Flipper R0.12 не запускался и FPS не замерен.

Прошивку, прежние сохранения, отдельный PikaCore и неизменяемую цифровую идентичность HTask1k0 не затрагивали. Права на графику и игровые данные принадлежат правообладателям. Частная разработка и тестирование.
