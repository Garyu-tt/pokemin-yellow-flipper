# Pokémon Yellow Native — R0.12-B

**Частичный нативный порт Pokémon Yellow для Flipper Zero.** Это не эмулятор Game Boy и не завершённая игра. SDK: Momentum `mntm-012` API 87.1, ARM Cortex-M4, 128×64.

## Реализовано

- Общий обработчик атаки для обеих сторон: PP (для активного покемона игрока), пропуск хода из-за паралича, проверка точности, критический удар, расчёт повреждений, основной эффект, вторичный эффект, поражение и вынужденная замена.
- Единое применение Growl, Tail Whip, Sand Attack, Double Team, Thunder Wave и побочных эффектов ThunderShock, Thunderbolt и Hyper Fang. Противник и игрок используют тот же код эффектов; ограниченный ИИ Route 1 пока выбирает только подмножество этих атак.
- Корректное ограничение модификаторов характеристик от −6 до +6; симметричные модификаторы атаки, защиты, точности и уклонения.
- Исправлен выход из меню переключения команды обратно в боевой экран при обработке в общем конвейере.
- Изолированные сохранения `/ext/apps_data/yellow_native/save_v12b.dat`, при первом старте валидные данные из предыдущего `save_v12.dat` импортируются в отдельный файл. Поскольку структура R0.12-A и R0.12-B идентична, числовая версия сериализованного формата остаётся 12. Старые сохранения, R0.11 и R0.10, остаются на месте.
- Введён отдельный регрессионный тест `test_pipeline12b.c`: обе стороны, статусы, границы стадий, лечение, наносимый урон, полный проигрыш, PP и паралич.

## Доказательства

- Хостовые C-наборы: test_core, test_negative, test_route04, test_battle05, test_capture06, test_party07, test_effects08, test_turns09, test_moves10, test_state_stress10, test_move_forget11, test_type12, test_migration12, test_pipeline12b — PASS.
- Проверки первоисточников `test_original_data.py`, `test_type_source12.py` — PASS.
- Стресс-тест 16 000 переходов состояния с сохранениями — PASS.
- ARM SDK: сборка, линковка, APPCHK — PASS.
- Физический Flipper и FPS **не проверены**.

## Незавершённое

В полной Gen1 реализации ещё нужны временные статусы (сон/ожог/отравление/заморозка), конец хода, точное RNG-потребление, самоурон, recoil, ходовые эффекты, оригинальные ошибки/особенности. Текущий конвейер поддерживает только реально портированные атаки; отбой от отсутствующего эффекта явно не объявляется готовым. Далее: R0.12-C, потом Route 2 / Viridian Forest.

Без изменения прошивки, Noosphere Pika и неизменяемой персональной идентичности HTask1k0. Старые файлы сохранения не удаляются.

Данные и графика Pokémon остаются собственностью правообладателей, оригинал: https://github.com/pret/pokeyellow, закреплённый commit указан в `source_manifest.json`.
