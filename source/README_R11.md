# Pokémon Yellow Native R0.11 — 2026-10-23

**Это частичный нативный порт для Flipper Zero, не эмуляция Game Boy и не полностью портированная игра.** Совместимость FAP: Momentum `mntm-012`, API `87.1`, ARM Cortex-M4. Экран и камера: 128×64.

## Исправления и функции R0.11

- При обучении атаке с четырьмя занятыми слотами игра **больше не забывает старую атаку автоматически**. После текста о победе появляется родное для разрешения 128×64 меню.
- Стрелки Up/Down выбирают один из четырёх старых приёмов или **KEEP OLD / SKIP**. OK заменяет только выбранный слот, полностью обновляя его PP. BACK не изучает новую атаку и оставляет старые нетронутыми.
- Очередь поддерживает последовательность нескольких новых атак, полученных в одном бою (например, при нескольких повышениях уровня). Перемещение в мире и новое сражение не прерывают обязательное решение.
- Текущий игровой прогресс сохраняется с новым форматом `save_v11.dat`, не затрагивая файл `save_v10.dat`. Если новой версии ещё нет, игра проверяет контрольную сумму и семантику старого R0.10-сохранения, переносит прогресс в новый формат и записывает отдельный файл. При ошибке миграция отклоняется без повреждения исходника.
- Поддержаны особые случаи: отмена обучения, повторно уже известная атака, очередь нескольких приёмов, сохранение PP неизменённых атак, обучение после фактической победы.

- `tests/test_original_data.py` сравнивает данные с закреплённым pret/pokeyellow — PASS.
