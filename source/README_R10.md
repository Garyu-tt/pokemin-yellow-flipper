# Pokémon Yellow Native — R0.10 (Flipper Zero)

**Частичный нативный порт, а не эмулятор Game Boy и не вся оригинальная игра.**
Платформа: Flipper Zero / Momentum `mntm-012` SDK API 87.1. Экран 128×64, пиксели мира без масштабирования.

## Выполнено в R0.10

- Добавлены отдельные массивы **идентификаторов выученных атак** и их PP для Пикачу и каждого пойманного покемона (четыре слота, сохраняемые на microSD).
- Убрана зависимость боевого интерфейса от реконструкции списка атак исключительно по уровню: каждый покемон теперь сражается своим сохранённым набором.
- Расписания обучения, взятые из закреплённого `pret/pokeyellow/data/pokemon/evos_moves.asm`: Пикачу уровни 6/8/11/15/20/26, Пиджи 5/12, Раттата 7/14. Более поздние атаки и эволюции по-прежнему не завершены.
- Добавлены оригинальные свойства **Thunder Wave** (PP20, паралич), **Double Team** (PP15, повышение уклонения), **Slam** (80 power, точность 75), **Thunderbolt** (95 power, шанс паралича), **Hyper Fang** (80 power, 90 точность, 26/256 шанс испуга и пропуска второй атаки при атаке первым).
- Подключена уклоняемость: Double Team повышает evade-stage, и теперь противник проверяет попадание с этим модификатором.
- **Временная политика:** когда заполняются все 4 слота, новая атака автоматически заменяет самую старую. Это *не* оригинальная механика выбора забываемого приёма; полноценный интерактивный выбор запланирован.
- Исправлен дефект сохранений, найденный стресс-тестом: Pikachu может иметь 0 HP, если другие покемоны остаются боеспособными. Загрузка корректно выбирает выжившего участника.
- `save_v10.dat`: новая независимая версия с проверкой допустимых видов атак, лимитов PP, дубликатов, порядка слотов и контрольной суммы. Старые сохранения не перезаписываются и автоматически не мигрируют.

## Ограничения и безопасность

- Прототип охватывает всего семь оригинальных игровых областей и три доступных игровых вида, сокращённое вступление и экспериментальный боевой движок. Оригинальные AI, все статусы, снаряжение, полная партийная логика, обмен, покедекс, эволюции, звук и весь Канто отсутствуют.
- Физический запуск и FPS на Flipper ещё **не проверены**. По SSH ноутбук доступен, но подтверждённого доступа к USB Flipper и версии прошивки в этом релизе нет.
- `yellow_native` — отдельное приложение; PikaCore/Noosphere Pika и индивидуальное неизменяемое имя HTask1k0 не изменяются. Не перепрошивать Flipper без отдельного проверяемого процесса и отката.
- Ресурсы из https://github.com/pret/pokeyellow (commit в source_manifest.json). Pokémon принадлежит правообладателям; частные испытания, без утверждения права публичной дистрибуции.
